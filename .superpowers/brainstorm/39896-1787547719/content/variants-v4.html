How Base/GST reacts to GST Mode

  • GST Mode = "Include GST" (shown above): Amount is treated as inclusive — Base + GST line shows the split hidden inside that number (matches your reference screenshot exactly).
  • GST Mode = "Exclude GST" (if switched): Amount is the base itself — the line below would instead read something like "+ GST: ₹18 → Total: ₹138", since there's nothing to "split out" of an exclusive amount.
  • Tax % (Row 1) drives the GST math for both Sale and Purchase Base/GST lines on this variant — one tax rate per variant, applied to whichever Amount+Mode you set per price type.
